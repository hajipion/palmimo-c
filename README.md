# Palmimo 視力チェック

Palmimo が視力検査の検査員になるアプリです。顔の画面にランドルト環（切れ目のある輪）を出し、
受検者は切れ目の向きを声で答えます。

**結果は目安です。医療用の検査ではありません。**

## 流れ

1. 「それでは検査をはじめます。検査をする人は手をあげてください。」と言い、カメラで手を挙げた人を見つけます。
2. 「（服の説明）をきた、あなたですね。それでは、私と十分な距離をとってください。」と言い、顔までの距離を測ります。
3. めざす距離（既定 2 m）になるまで「もう少し、さがってください。」などと声をかけます。少し遠いときは Palmimo が前に出ます。20 秒たったら、その時点の距離で始めます。
4. 「それでは、視力検査を開始します。対象との距離、1.8 メートル。ランドルト環のサイズを調整中。調整完了。それでは、いきます。」
5. 顔に環を出して「これは？」と聞きます。「うえ」「みぎ」などが聞こえたら、すぐ次の環へ進みます。
6. 「おつかれさまでした。あなたの視力は、0.7 です。」と結果を伝え、一言添えておじぎして終了します。

## しくみ

| すること | 方法 |
|---|---|
| 環を顔に出す | 顔基板のファームウェアの `FRAME` 命令で、169×169 の画像を送ります |
| 環の大きさ | 切れ目が視角 1/V 分になる幅、外径はその 5 倍。測った距離と顔画面の直径から計算します |
| 出題 | 出せる範囲（1 m で 0.1〜0.5、2 m で 0.2〜1.0、3 m で 0.3〜1.5）を小さいほうへ。1 問正解で次へ、間違えたらその大きさを 3 問中 2 問で判定します |
| 距離 | カメラの画像から両目の間隔を取り（YuNet）、63 mm と仮定して距離に直します |
| 手を挙げた人 | カメラの画像を OpenAI の画像モデルに送り、手挙げと服の色を判定します |
| 声の回答 | マイクを流しっぱなしで受け、話し終わりを検出（Silero VAD）して OpenAI で文字起こしします |

`FRAME` 命令は palmimo-sdk の公開 API にはありません。Palmimo Portal が Wi-Fi 設定の QR コードを
顔に出すのと同じ命令を、`FaceDisplay` の内部の送信口から送っています（`palmimo_vision_check/rig.py`）。

## Palmimo に入れる

Portal の「アプリを追加」から、このリポジトリの URL か zip（`git archive -o vision-check.zip HEAD`）で入れます。
起動すると検査が 1 回流れて終了します。

| 設定 | 既定 | 意味 |
|---|---|---|
| `port` | 8010 | 予備の回答ページのポート番号 |
| `distance_m` | 2.0 | めざす距離（m）。環の大きさは実際に測った距離で決まります |
| `settle_seconds` | 20 | 距離合わせを打ち切って検査を始めるまでの秒数 |
| `panel_mm` | 60 | 顔画面の光っている部分の直径（mm） |
| `walk_seconds` | 0.8 | 近づくときに 1 回で歩く秒数（最大 3 回）。0 で歩きません |
| `camera_hfov_deg` | 53.5 | カメラの水平画角（度）。距離の読みがずれるときに直します |
| `vision_model` | gpt-5-mini | 手を挙げた人を見つける画像モデル |
| `speaker_device` | ReSpeaker | スピーカーの機器名の一部。見つからなければ標準の出力を使います |
| `no_motion` | オフ | 脚と首を動かしません |
| `no_voice` | オフ | マイクを使わず、ページのボタンで答えます |

環境変数 `OPENAI_API_KEY` を設定すると、声での回答と手挙げの判定が有効になります。
本体内の読み上げが使えないときは、OpenAI の読み上げに切り替えます。
無い場合は、予備のページのボタンで進めます。

### 予備のページ

起動中は `http://<Palmimo>:8010/` で、いま出している環の見本と、上下左右・「わからない」・
「次へ進める」（手挙げ待ちと距離合わせを飛ばす）のボタンが使えます。

## 手元で試す

```sh
uv sync
uv run palmimo-vision-exam --dry-run   # 機器を開かずに流れだけ。http://localhost:8010/ で回答
uv run pytest -q
uv run ruff check .
uv run mypy
```

## 精度について

- 顔画面の直径、カメラの画角、両目の間隔はどれも仮定の値で、それぞれ 1 割ほどずれることがあります。
- 環は 1 画素 約 0.25 mm の粗さで描いています。いちばん小さい環の切れ目は 2 画素ほどで、これより小さい環は出せません。近いほど測れる上限が下がります。
- 画面の明るさとコントラストは合わせていません。背景は黄色です。
- 1〜3 m での結果で、標準の 5 m の遠見視力とは別のものです。両目で見た値です。

## 外部に送るデータ

`OPENAI_API_KEY` を設定した場合、カメラの画像（手挙げの判定のあいだ）と、回答の音声が OpenAI に送られます。
結果はログに出るだけで、ファイルには保存しません。
